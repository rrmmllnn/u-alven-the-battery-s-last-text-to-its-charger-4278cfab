A [make.fun](https://make.fun/c/u-alven-the-battery-s-last-text-to-its-charger-4278cfab) entry for
"The Battery's Last Text to Its Charger": one line of plain text, at most
200 characters — the phone battery's final message to the charger it
waited for all day.

`main.py` writes that one line to `/output/entry.txt`, deterministically,
every run.
